# Calendar-Bulk-Edit
A java program to edit calendar events in bulk.

## Project Goal
The goal of this project is to create a text-based tool to edit multiple iCalendar events based on filters. More advanced features and a GUI could be added later.

## MVP Scope
 - File input works
 - File data is correctly turned into object(s)
 - Events can be filtered
 - Selected events can be edited in bulk
 - Updated iCalendar file can be exported

## Future Plans
 - Intuitive GUI to make it easier to interact with
 - Advanced filters and editing capabilities
 - Custom/experimental iCalendar features
